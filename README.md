# Quiz Up

Quiz interativo para computador, telemóvel e iPhone, preparado para publicação através da pasta `docs` do GitHub Pages.

## Ficheiros da pasta `docs`

- `index.html`: aplicação completa do Quiz Up.
- `quizup-banco-unico.json`: banco com 1000 perguntas únicas.
- `README.md`: documentação desta versão.

## Funcionalidades

- 1000 perguntas únicas organizadas por categoria e dificuldade.
- Equipas, pontuação, temporizador e classificação final.
- Modos manual e automático.
- Controlos por teclado: A, B, C, D, setas e espaço.
- Botão de ecrã inteiro disponível durante o quiz.
- Perguntas falhadas e estatísticas por equipa e categoria.
- Formulário integrado para adicionar perguntas no navegador.
- Reposição do banco original.
- Layout Mobile First otimizado para iPhone e Safari.
- Vercel Web Analytics preservado.

## Publicação

Substitui os três ficheiros existentes dentro da pasta `docs` do repositório. Mantém o GitHub Pages configurado para publicar a partir da pasta `/docs` da branch utilizada pelo projeto.
