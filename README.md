#Quiz de Bar
Website estático pronto para publicar no Vercel.

Publicar no Vercel
Extraia este ZIP.
Entre no painel do Vercel.
Crie um novo projeto e carregue esta pasta, ou use a Vercel CLI na pasta.
Não é necessário comando de build. O ficheiro de entrada é `index.html`.

Funcionalidades
1000 perguntas geradas localmente por categorias
Equipas, temporizador, pontuação e modo automático
Histórico no localStorage
Importação e exportação JSON
Persistência do banco importado no localStorage
Validação de perguntas e IDs duplicados
Funciona sem servidor e sem base de dados
